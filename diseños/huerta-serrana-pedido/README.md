# Huerta Serrana — Pedido de demostración

Abre `index.html` para revisar el carrito compartido con la [maqueta del catálogo](../huerta-serrana-catalogo/), introducir datos ficticios y revisar la confirmación. Al confirmar se abre `gracias.html` con una referencia aleatoria de demostración. La referencia no es un número de pedido real ni permite seguimiento.

No se envía, guarda ni tramita ningún pedido y no se realiza ningún pago. Los datos del formulario permanecen únicamente en la página durante la demostración: no se envían ni se incluyen en la URL o el almacenamiento. No introduzcas datos personales reales. El carrito de ejemplo se conserva después de confirmar.

Los productos y unidades del carrito siguen siendo provisionales; la confirmación los muestra con imágenes y cantidades, pero sin importes hasta validar las correspondencias con las fuentes. El resumen reserva espacio para el IVA y el envío, sin asumir importes ni si el IVA está incluido. El flujo no implementa pagos, condiciones comerciales ni disponibilidad. La maqueta reutiliza estilos del catálogo y las interacciones compartidas de productores; las fuentes de Google requieren conexión y deben revisarse antes de producción.
